# tg-tracker — Privacy Policy

tg-tracker is a personal tool used only by its owner (Anna Ilina).

- It reads the owner's own Gmail mailbox to move unwanted messages to Trash
  and to send the owner a daily summary in Telegram.
- Data is processed only on the owner's own server and is not shared with,
  sold to, or disclosed to any third party.
- Only message metadata (subject, sender, short snippet) is stored, and only
  for the purpose of the summary; it is deleted automatically over time.
- Access can be revoked at any time at https://myaccount.google.com/permissions
